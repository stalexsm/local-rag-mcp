# Context: Локальная RAG-система с MCP

Локальный ассистент по корпоративной базе знаний: извлечение чанков документа
двумя ретриверами, слияние выдачи и генерация ответа маленькой локальной LLM.
MCP-инструменты дают внешний доступ к документам, но не участвуют в ранжировании.

## Language

**Чанк**:
Единица извлечения: фрагмент документа с текстом, источником и номером внутри документа. Один и тот же набор чанков обслуживает оба ретривера.
_Avoid_: фрагмент, кусок, документ (документ — это целый файл)

**Ретривер**:
Компонент, возвращающий ранжированный список чанков по запросу.
_Avoid_: поиск (не говорит, какой), поисковик

**Векторный ретривер**:
Ретривер, находящий чанки по семантической близости эмбеддингов.
_Avoid_: семантический поиск, FAISS-поиск

**FTS (полнотекстовый поиск)**:
Ретривер, находящий чанки по дословному совпадению слов запроса со словами чанка; ранжирует BM25.
_Avoid_: лексический поиск, полнотекст, FTS5

**Query Expansion**:
Шаг перед поиском: LLM извлекает из вопроса пользователя ключевые слова, которые передаются в ретриверы вместе с исходным запросом.
_Avoid_: генерация ключевых слов, keyword generation, расширение запроса

**Пул кандидатов**:
Список чанков, который каждый ретривер отдаёт до слияния; финальная выдача выбирается из объединённого пула.
_Avoid_: candidates, претенденты, топ

**RRF (Reciprocal Rank Fusion)**:
Слияние двух ранжированных списков по позициям чанка в каждом, а не по исходным скорам.
_Avoid_: переранжирование, взвешенное слияние

**Fallback**:
Поведение при сбое ступени: поиск продолжается на уцелевших ступенях (сбой Query Expansion → исходный запрос; сбой FTS → только векторный; сбой векторного → только FTS).
_Avoid_: деградация, graceful degradation
