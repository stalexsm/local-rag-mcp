# Метки триажа

Скиллы оперируют пятью каноническими ролями триажа. Этот файл сопоставляет роли с фактическими строками меток в трекере этого репозитория.

| Роль в mattpocock/skills | Метка в нашем трекере | Значение |
| ------------------------- | --------------------- | -------- |
| `needs-triage`            | `needs-triage`        | Мейнтейнер должен оценить issue |
| `needs-info`              | `needs-info`          | Ожидается дополнительная информация от автора |
| `ready-for-agent`         | `ready-for-agent`     | Полностью специфицировано, готово для агента без присмотра |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком |
| `wontfix`                 | `wontfix`             | Обрабатываться не будет |

Когда скилл упоминает роль (например, «навесь метку готовности для агента»), используйте соответствующую строку метки из таблицы.

Правую колонку можно отредактировать под ваш реальный словарь меток.
